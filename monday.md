🏗️ About Orlanda Engineering

Orlanda Engineering is a facade engineering company. We design, calculate, and produce technical drawings for aluminum cladding, glazing, and facade systems on construction projects across Israel and beyond.

Our workflow runs entirely through Monday.com — every task, every project, every document number lives here.

✅ Creating a Task — 5 Mandatory Rules

Rule 1 — Task Name Format

Project Name — Facade / Level / Surface (RAL color)

Good examples:

Aqua Sence Netanya — Facade North, Level 7-11, Surface 6L (RAL 9016)

Symphony Holon — Facade East, Level 20 (RAL 7022)

BERLIN 3 Project — Estimation for offer

Bad examples: "New drawing", "Serdar task", "Panels"

Note: The project name is already in the Linked Project relation — do NOT repeat it separately.

Rule 2 — Assigned Person

Always assign a specific team member. Unassigned tasks are invisible in analytics.

Rule 3 — Linked Project

Connect the task to the relevant project in board 🔴 2. Projects.

If you cannot meet your deadline:

Write an update in the task with the reason

Mention your manager with @name

Update the deadline to the new expected date

Never silently move a deadline

🔔 Updates and Notifications

All communication about a task must happen INSIDE the task — not WhatsApp, not email.

When to write an update:

When you start working (status change)

When you hit a blocker

When you receive client feedback or files

When you send drawings

When you need something from a colleague

How to mention someone:

Use @name in the update — they get a Monday notification.

Example: @Karash — received client comments, need revision on Level 12-15

URGENT tasks:

Acknowledge in the task updates immediately

Start first thing next morning at the latest

Do not add to backlog — it skips the queue

📄 Document Numbers — The Code System

Format: CLIENT - DESIGNER - PROJECT - TYPE - YEAR - MONTH - SERIAL

Example: AMR-DOV-AQU-HP-2026-03-4298

AMR = Client (Amram Avraham)

DOV = Designer (Dovran)

AQU = Project (Aqua Sence)

HP = Type (Hipuy = Production drawing)

2026-03 = Year and month

4298 = Serial number
